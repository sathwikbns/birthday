# Sketch Manifest

## Design Direction
Cinematic / editorial — dramatic full-bleed sections, bold type hierarchy, feels like a movie tribute or fashion magazine spread. Every section should deliver a "wow" moment equally. Key problem being solved: fonts look great on desktop but suck on mobile. Fix with fluid responsive typography throughout.

## Reference Points
- Film title sequences (dramatic, full-bleed, typographic)
- Editorial magazine layouts (Vogue, Kinfolk)
- Cinematic apps (Apple TV+, Letterboxd, A24 website)
